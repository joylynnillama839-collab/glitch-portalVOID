GLITCH PORTAL: VOID SHIFT — Improved Edition

HOW TO PLAY
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Choose a sector and click START.
4. Move with A/D or the arrow keys. Jump with W, Up Arrow, or Space.
5. Collect the three cyan energy shards and enter the purple portal.
6. Press R to restart a sector and Esc to open the menu.

FEATURES
- 10 progressively challenging sectors
- Responsive layout for desktop and mobile
- Keyboard and basic touch controls
- Collectible shards, spikes, moving laser hazards, and a portal-shuffle trap
- Optional looping sci-fi background ambience and sound effects (toggle with “Sound: On”), timer, death counter, and sector selection
- No installation or build tools required

NOTES
The game uses a Google Fonts import for optional typography; it still works if you are offline.

Compatibility fix: the player uses a basic canvas path instead of CanvasRenderingContext2D.roundRect, so it can render in older external browsers and webviews.

BACKGROUND SOUND
Click “♫ Sound: On” to enable a soft, looping sci-fi ambience and game sound effects. Click again to mute them. Browsers require a click before audio can start.
